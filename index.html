🔌 NoNamedCat KiCad Plugin Repository

A custom KiCad Plugin and Content Manager (PCM) repository.

Repository URL — paste this into KiCad PCM:

https://nonamedcat.github.io/JLC_Library_Gen/repository.json

How to install

  1. Open KiCad → Plugin and Content Manager
  2. Click Manage Repositories…
  3. Click + and paste the URL above
  4. Click OK — the plugin will appear in the list
  5. Select JLC Library Gen and click Install

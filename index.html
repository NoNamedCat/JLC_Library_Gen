📖 How to Install Plugins from this Repository

  1. Open KiCad → Plugin and Content Manager (PCM).
  2. Click Manage Repositories… at the bottom.
  3. Click + and paste: https://nonamedcat.github.io/JLC_Library_Gen/repository.json
  4. Click OK → All plugins below will appear in your PCM catalog!
